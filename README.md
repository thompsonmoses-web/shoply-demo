# Shoply demo (built site)

Public demo build of the private Shoply source repository. This repository contains
only compiled frontend assets and the demo landing page.

- Storefront: https://thompsonmoses-web.github.io/shoply-demo/storefront/
- Admin studio: https://thompsonmoses-web.github.io/shoply-demo/admin/
- Landing: https://thompsonmoses-web.github.io/shoply-demo/

The admin studio requires a seeded Shoply admin account. Demo credentials are shared
privately. No real payments are processed. This is a review build, not a production
deployment.
